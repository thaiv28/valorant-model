# valorant-model

A pre-map trading model for Valorant esports: player-based round Elo, a map layer and a veto model, priced against Kalshi's Valorant series and map-winner markets. The design is in [docs/design_plan.pdf](docs/design_plan.pdf); agent and contributor guidance is in [AGENTS.md](AGENTS.md).
